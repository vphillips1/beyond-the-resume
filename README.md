# Beyond the Resume

A collaborative portfolio website showcasing the skills, experience, and projects of our team members.

## About the Project

Beyond the Resume is a collaborative web development project created by a team of four students. The purpose of this project is to create an interactive portfolio website that allows employers to learn more about potential candidates beyond what a traditional resume can show.

The website features a homepage where visitors can explore individual profile pages for each team member. Each profile highlights personal backgrounds, education, technical skills, experience, and projects.

## Project Features
- **Homepage:** Introduces the team and provides navigation to each member's profile.
- **Individual Profiles:** Personalized pages showcasing each team member's background, skills, education, and experience.
- **Project Showcases:** Displays completed projects and examples of individual work.
- **Contact Information:** Provides ways for employers to connect with team members.
